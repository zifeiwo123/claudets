# Codex / Claude Handoff

This folder is the durable handoff lane between Codex and Claude for the
`claudets` project.

Every agent that changes the repo should update this file before handoff:

1. Add what was changed.
2. Add what was verified.
3. Add what remains unsafe or preliminary.
4. Add the next request for the other agent.

Keep this file ASCII-safe unless the user explicitly asks for Chinese text in
the file. The repo has had encoding drift before, so plain ASCII is preferred.

---

## Standing Rules

- Do not restart GP unless the user explicitly asks after an audit.
- Do not enter Phase 2 while the final holdout remains only a preliminary pass.
- Do not edit source data parquet/db files.
- Reports must be generated from a single result source whenever possible.
- Do not manually paste strategy, benchmark, excess, NAV, turnover, or cost
  numbers from separate runs into the same report.
- For weekly strategies, state whether a date is `signal_date` or
  `return_end_date`.
- Use `preliminary pass` unless all metrics are single-source reproducible and
  residual report-generation risks are resolved.
- Keep new governance docs ASCII-safe to avoid mojibake.
